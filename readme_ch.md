# Obsidian MD Opener

[English](readme_en.md)

**在 Windows 资源管理器里双击 Markdown，就能用 Obsidian 打开原文件，省掉临时建库、再找一遍笔记的步骤。** 
如果项目里的文件太多，或检查目录时间超过 1.2 秒，打开器会优先用轻量仓库打开笔记，省去加载整个项目的等待，这可能是很长时间（比如10分钟=-=）。
通过打开器切换本机仓库时，快捷键、外观和常用插件设置会自动同步，无需在每个仓库手动同步配置。

## 工具初衷

捞逼产品（也就是我）经常用 Obsidian 看散落在桌面和项目里的 Markdown。有时已经在资源管理器里找到了要看的笔记，可它所在的文件夹还没加为仓库。我得先把文件夹加进 Obsidian，再把同一篇笔记找一遍。

第一版会把笔记所在的文件夹直接加成仓库。遇到有几千个构建文件的项目，只想看一份文档也得等整个目录加载（花了20分钟没打开，干！！）。后来我加了轻量仓库。打开笔记时，Obsidian 可以跳过项目里的无关文件，编辑后保存的还是原文件。

## 举个例子

假设你想看这个项目里的 `README.md`。

```text
项目/
├── README.md
├── 部署说明.md
├── 输出/
│   └── 测试计划.md
└── 构建产物/     （很多文件）
```

在资源管理器里双击 `README.md`。这个项目有大量构建产物，打开器会把这篇笔记和能找到的附件接入轻量仓库，Obsidian 无需扫描整个项目。如果打开的是小目录里的笔记，就直接用它所在的文件夹。

想接着看测试计划，就在 Obsidian 的「按需文件浏览」侧栏展开 `输出/`，点开 `测试计划.md`。

如果一次要看几篇笔记，可以在资源管理器里多选后一起打开。

## 安装

适用于 Windows。请先安装并启动过一次 Obsidian。

1. 用「Windows PowerShell」打开项目目录，运行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1`。程序会生成在 `bin\ObsidianMdOpener.exe`，可以将它移到固定位置。
2. 在资源管理器右键任意 `.md` →「打开方式」→「选择其他应用」→「在电脑上选择应用」，选中这个 EXE，然后将它设为默认应用。
3. 在资源管理器里双击一份 `.md` 文件，Obsidian 就会打开这篇笔记。

**想在侧栏看同目录的文件？** 打开器会自动安装「按需文件浏览」插件。点击 Obsidian 左侧工具栏的文件树图标即可打开侧栏。如果看不到图标，在当前仓库的「设置 → 社区插件 → 已安装插件」里确认「按需文件浏览」已启用。

**首次打开时提示仓库登记失败？** 从 Windows 系统托盘的 Obsidian 图标菜单退出程序，再双击原来的 `.md` 文件。
