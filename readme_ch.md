# Obsidian MD Opener

[English](readme_en.md)

**在 Windows 资源管理器里双击 Markdown，Obsidian 就打开你眼前这篇。临时建库、进仓库再找一遍笔记，这两步都省了。**

只想看一篇笔记，也能等上好一阵（比如 10 分钟 =-=）。所以遇到文件太多的项目，或者光检查目录就花了 1.2 秒，打开器会优先用轻量仓库。换到本机另一个仓库时，快捷键、外观和常用插件设置也会自动同步。刚调顺手的东西，谁想再配一遍啊。

## 工具初衷

捞逼产品（也就是我）经常用 Obsidian 看散落在桌面和项目里的 Markdown。最烦的是，文件明明已经找到了，我还得先把它所在的文件夹加为仓库，然后在 Obsidian 里把同一篇笔记再找一遍。

第一版替我把笔记所在的文件夹加成了仓库。我拿一个有几千个构建文件的项目试了试。只想看一篇文档，Obsidian 却开始加载整个项目（花了20分钟没打开，干！！）。

这才有了轻量仓库。碰到这种大项目，就先把眼前这篇笔记和能找到的附件接进 Obsidian。**按下保存，改的还是原文件。**

## 举个例子

```text
项目/
├── README.md
├── 部署说明.md
├── 输出/
│   └── 测试计划.md
└── 构建产物/     （很多文件）
```

我要看 `README.md`，就在资源管理器里双击它。`构建产物/` 里还有几千个文件？让它们待着，我先看笔记。要是文件夹本来就很小，打开器会直接用它当仓库。

读到一半想对照测试计划，在 Obsidian 的「按需文件浏览」侧栏展开 `输出/`，再点 `测试计划.md`。要是一开始就知道两份都要看，也可以直接在资源管理器里多选后一起打开。

## 安装

1. 在 Windows 上安装 Obsidian，先启动一次。
2. [下载 Windows 打开器](https://github.com/95490164/Obsidian-MD-Opener/releases/latest/download/ObsidianMdOpener.exe)，把 `ObsidianMdOpener.exe` 放在一个以后不用挪动的文件夹。
3. 在资源管理器里右键任意 `.md` 文件，依次选「打开方式」→「选择其他应用」→「在电脑上选择应用」。选中刚下载的 EXE，设为默认应用。下次双击笔记就行。

想自己编译的话，项目里也有 [Windows PowerShell 构建和测试步骤](CONTRIBUTING.md)。

**找不到侧栏？** 打开器会自动安装「按需文件浏览」。点 Obsidian 左侧工具栏的文件树图标。如果连图标也没看到，到当前仓库的「设置 → 社区插件 → 已安装插件」里确认它已启用。

**第一次打开就提示仓库登记失败？** 从 Windows 系统托盘的 Obsidian 图标菜单退出程序，再双击原来的笔记。

附件、跨盘打开和设置同步的细节见[使用说明](CONTRIBUTING.md)。这是个依赖本机 Obsidian 的独立项目，按 [MIT 许可证](LICENSE)开源。
